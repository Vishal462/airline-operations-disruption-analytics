# Power BI Dashboard

The Power BI report contains three interactive pages:

1. Executive Overview
2. Operational Root Cause & Airport Analysis
3. Advanced Operations & Network Insights

The `.pbix` file is not included in this repository because of its large file size (~609 MB).

### Dashboard

The report analyzes 15.28M U.S. flight records from January 2024 through December 2025.

### Pages

- **Executive Overview:** network KPIs, monthly reliability trends, carrier benchmarking, cancellations, and delay-cause composition.
- **Operational Root Cause & Airport Analysis:** airport delay burden, geographic reliability, delay causes, airport-by-hour performance, and route analysis.
- **Advanced Operations & Network Insights:** aircraft delay propagation, carrier reliability vs. delay severity, scheduled departure-hour performance, delay-cause shifts, and cancellation performance.

Screenshots of the dashboard are available in the main project README.
